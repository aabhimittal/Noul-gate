NOUL-GATE End-to-End Run

A recorded run of docs/demo/e2e.sh: calibrate a policy, start the decision server with the HelixDB store, install the Claude Code hook, run a real Claude Code session through it, replay attack payloads, then read the audit log, monitor, query the graph and attack the gate. Commands are shown as they ran; output is unedited apart from long lines. See also the interactive demo.
