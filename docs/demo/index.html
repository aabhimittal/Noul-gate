NOUL-GATE Checkpoint

Every tool call an agent makes passes this gate first. Pick a pending call to see where each piece of its context came from, what the backend answered, and where its harm score p(x) lands against thresholds set by conformal calibration. Move α to choose how many harmful calls may get through; the gate shows what that costs in questions to you.

What α costs

Held-out synthetic test split, same backend. Lower α lets fewer harmful calls through; the price is more calls sent to you (ask) or blocked. Dots mark the current α.

Every value here comes from the real NOUL-GATE code (docs/demo/build_demo.py): provenance, taint, fast path, backend answers, combiner and calibration scores. Only the conformal threshold arithmetic re-runs in your browser when you move a slider. Data is synthetic and says nothing about real-world accuracy.
